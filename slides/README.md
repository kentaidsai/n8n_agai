# 投影片　— 用 n8n 實現 Agentic AI System

本資料夾收錄「用 n8n 實現 Agentic AI System」14 小時課程投影片的**響應式網頁播放版不需 PowerPoint 或 Claude 帳號即可開啟；以**投影片播放**方式呈現（一次顯示一張、可上一頁／下一頁／全螢幕），並會依螢幕寬度（手機／平板／桌機）自動縮放版面。

## 檔案清單

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 索引首頁，列出 7 份模組版的連結（點選後於新視窗／分頁開啟） |
| `Module1_Slides.html` ～ `Module7_Slides.html` | 7 份依模組拆分的獨立投影片播放網頁（張數依模組不同，5～7 張不等） |

> 本資料夾僅收錄依模組拆分的 7 份版本；44 張的完整總覽版請使用線上 Slides。

## 為什麼另外做這一份

- **免安裝、免帳號**：這份 HTML 版本用任何瀏覽器就能開啟，方便放上內部網站、隨附教材光碟／隨身碟，或在沒有裝 Office 的裝置上快速播放。
- **投影片播放體驗**：畫面一次只顯示一張投影片並填滿可視區域，操作方式比照一般簡報軟體——上一頁／下一頁、全螢幕、鍵盤快捷鍵、觸控滑動皆支援，適合實際上課簡報使用，而不只是瀏覽內容。
- **響應式（RWD）**：每張投影片維持原始 1920×1080 的設計（字體、配色、版面完全不變），外層以 JavaScript 依可視區域即時計算縮放比例，因此同一個網頁在桌機、平板、手機上都能完整顯示。

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（雙擊檔案，或拖曳到瀏覽器視窗）。
2. 點選任一模組卡片，會在**新視窗／分頁**開啟對應的投影片播放頁。
3. 進入投影片播放頁後：
   - **換頁**：點選畫面左／右側區域、下方 ◀／▶ 按鈕，或使用鍵盤方向鍵／PageUp／PageDown／空白鍵；手機／平板可左右滑動切換。
   - **跳頁**：頁面右上角有「跳到指定投影片」下拉選單，可直接選擇任一張投影片；旁邊的「切換章節」下拉選單可直接換到其他模組（同頁面切換，不會另開新視窗）。
   - **全螢幕**：點選下方 ⛶ 按鈕或按 `F` 鍵進入全螢幕播放，再點一次或按 `Esc` 離開全螢幕。
   - 畫面下方會顯示目前頁碼（例如 `2/5`）與播放進度條；左上角「← 索引」可回到索引首頁。
4. 若要放上內部網站或分享給學員，直接將整個 `slides/` 資料夾（含 `index.html` 與所有 `.html` 檔）一併複製或上傳即可；請保持資料夾內檔案相對路徑不變，否則模組間的互相切換會失效。

## 已知小提醒

- 少數投影片（例如 Module 1 的節點對照表）內容較多，在原始設計中即已接近版面下緣，縮放後在極窄的視窗（例如手機直向、全螢幕但視窗很矮）可能會與頁尾文字略為貼近；這是原始投影片設計本身的留白調整範圍，非本次轉換造成，不影響內容完整性。
